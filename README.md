# Supplement E-commerce Website

## Description

A frontend e-commerce website designed for an online supplement store. The site allows users to browse products, interact with the shopping interface, and initiate purchases through the available payment and communication integrations.

## Features

- Product catalog
- Product browsing and selection
- Interactive shopping cart interface
- Responsive website layout
- Paystack payment integration
- WhatsApp customer enquiry/order communication

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Paystack JavaScript
- WhatsApp (`wa.me`) links

## Project Scope

This project is a **frontend implementation** and does not include a custom backend, PHP, database, or admin dashboard.
